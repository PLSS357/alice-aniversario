# Aniversário da Alice

Site interativo de aniversário, com minijogos, música e ilustrações.

## Como abrir

Abra o arquivo `index.html` em um navegador.

## Publicar no GitHub Pages

1. Crie um repositório chamado `alice-aniversario` no GitHub.
2. Envie **os arquivos desta pasta para a raiz** do repositório (sem a pasta `alice-aniversario-pronto`).
3. Vá em **Settings > Pages** do repositório.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main** e a pasta **/(root)** e salve.
6. O GitHub Pages disponibilizará o site no endereço indicado na seção Pages.

> A música `audio/musica.mp3` deve ser publicada somente com a autorização adequada para distribuição pública.

## Estrutura

- `index.html` — site principal
- `assets/` — imagens do site
- `audio/musica.mp3` — trilha sonora usada pelo site
